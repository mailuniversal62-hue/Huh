Credential harvester for **authorized penetration testing** and **security awareness training**.

## What it does

- Serves a cloned login page (Google / Microsoft / Instagram / Facebook / generic)
- Captures submitted form data (username, password, extra fields)
- Logs to local file + optional Telegram / Discord
- Redirects the victim to the real site so nothing looks broken
